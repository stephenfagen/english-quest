# English Quest (GitHub Pages-ready POC)

## Run locally
Open `index.html` in a modern browser. For GitHub Pages, upload the entire folder/repository and enable Pages from the repository Settings.

## CSV question format
`ID,Theme,Difficulty,Type,Question,Answer,AcceptableAnswers,Hint`
- `Theme`: rotation group; question themes are not repeated until the game exhausts available unique themes.
- `Difficulty`: 1-5.
- `AcceptableAnswers`: optional alternatives separated by `|`.
- UTF-8 CSV is recommended. Files can be uploaded from tablet storage using the in-game Teacher panel.
